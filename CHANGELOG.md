## [0.4.0] — 2026-09-14

### Добавлено
- Виджеты оверлея для OBS: отдельные URL `#/widget/<id>` — инвентарь, информация
  об игре (обложка + описание: Википедия приоритет, RAWG fallback), название игры
  (бегущая строка), статистика, таймер, профиль. Настройки видимости, порядок
  виджетов drag&drop и копирование готового URL в настройках.
- Соло-хотбар 2 ряда по 10: верхний — выбранные платформы (данные из таблицы),
  нижний — дополнительные платформы с кнопкой «+» и удалением крестиком.
- Клиент RAWG (обложки/скриншоты игр, ключ API в настройках) и Википедии
  (описания игр).
- Парсер Solo-таблиц с «шапкой» платформ (реальная структура стримеров:
  заголовки лежат на строку ниже шапки). Действия «Рерол»/«Дроп» распознаются.
- Иконки платформ для соло-хотбара, ник без слова «стример» в UI.
- Ключи API из `.env` (`scripts/sync-env.mjs`), скрипты для Google Sheets
  (разметка таблицы, выпадающие списки).

## [0.3.0] — 2026-09-13

### Добавлено
- Библиотека иконок предметов `@core/icons`: для каждого предмета банка
  (932 шт.) генерируется уникальная иконка — база по типу + цвет по имени +
  глиф по ключевым словам названия + звёзды раритета (1–6★). 100% покрытие банка.
- Отдельные иконки категорий инвентаря (Эффекты/Предметы/Спецроллы) и валют
  (монетки/слёзы). Спецролл — звезда с круговой стрелкой.
- Детальный вид предмета в попапе инвентаря: иконка, название, тип, количество,
  описание, эффект, раритет со звёздами и заметка.
- Solo RGG: детальный вид игры в попапе платформы (статус, причина,
  описание из таблицы), колонка «Описание» в парсере CSV.
- Автоочистка хотбара от «призраков»: слот закреплённого предмета, который
  пропал из инвентаря (или сменился ник/источник), автоматически становится
  пустым и удаляется из конфигурации.

### Исправлено
- Типизация Solo-парсера: убран небезопасный каст `as SoloPlatform`,
  платформа «Другое» теперь часть типа.
- Solo-режим больше не использует ник RGG Land как имя игрока.

## [0.2.0] — 2026-09-12

### Добавлено
- Баннер о доступном скачивании и автоскролл к блоку «Приложение».
- Кнопка «Проверить обновления»: пересборка манифеста из GitHub,
  поддержка прямых ссылок на релизы.
- Выбор формата нативной сборки под Linux (deb/rpm/AppImage).
- Логика запуска приложения вынесена в сервисы.

### Изменено
- Тёмная палитра Taiga принудительная; разделены фон страницы и фон бара.
- `transparentBg` делает прозрачной страницу; фон бара всегда свой.
- Фон страницы — тайговский тёмный `#222`.

### Прочее
- Commitlint (conventional-changelog) для проверки сообщений коммитов.
- CI: починено условие деплоя по `DEPLOY_KEY`.

## [0.1.0] — 2026-08-29

### Добавлено
- Первый релиз RGG Inventory — оверлей-инвентарь для RGG-стримеров
  (Angular + Tauri).
- Инвентарь в 2+ полосы с разворачиванием.
- Таймер с настройками отображения.
- Гибкие темы и авто-разметка дизайна по картинке.
- Источники данных: RGG Land, Google Sheets, локальный JSON.
- Tauri-оболочка: прозрачное окно поверх всех окон, обход CORS
  через plugin-http.
- GitHub Actions: нативные сборки всех ОС + публикация в Releases.
